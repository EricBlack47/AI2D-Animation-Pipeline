# Security Policy

If you discover a security issue, please report it privately and do not post it publicly.

## Reporting

Send security findings to the project maintainer through the normal issue tracker with the `security` label and minimal sensitive details.

## Supported versions

This project currently tracks the repository `main` development branch for fixes.

## Secret handling

- Do not commit `.env`, credentials, keys, or tokens.
- This project has no built-in secrets.
